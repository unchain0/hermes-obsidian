# Aplicar integridade no fechamento cron

Nunca processe lotes implicitamente: um item, uma transação lógica, uma validação e um fechamento observável.

## Segurança

Não copie memória, sessões, IDs, credenciais, dados pessoais, conteúdo restrito nem estado de execução para repositórios públicos.
