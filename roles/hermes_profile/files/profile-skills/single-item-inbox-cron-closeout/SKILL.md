# Fechar um item de inbox por execução

Adquira lock, processe um item estável, releia artefatos, valide integridade e encerre com resposta útil; falhas deixam o item recuperável.

## Segurança

Não copie memória, sessões, IDs, credenciais, dados pessoais, conteúdo restrito nem estado de execução para repositórios públicos.
