# Ingerir conteúdo público do JW.org

Use somente jw.org e wol.jw.org para conteúdo religioso, siga links relevantes, mantenha a fonte em 60-sources e sintetize em palavras próprias.

## Segurança

Não copie memória, sessões, IDs, credenciais, dados pessoais, conteúdo restrito nem estado de execução para repositórios públicos.
