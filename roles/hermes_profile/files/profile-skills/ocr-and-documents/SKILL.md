# Extrair texto de documentos

Detecte PDF textual versus digitalizado, aplique OCR quando necessário, registre a fonte e confira amostras antes de usar a extração.

## Segurança

Não copie memória, sessões, IDs, credenciais, dados pessoais, conteúdo restrito nem estado de execução para repositórios públicos.
