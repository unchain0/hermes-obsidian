# Rastreador de leitura bíblica

Confirme progresso somente após o usuário dizer “lido”. Use a data real em America/Sao_Paulo; não invente datas históricas. Releia o estado e a nota depois da atualização.

## Segurança

Nunca inclua tokens, IDs de chat, dados pessoais, conteúdo do vault real, estados de execução ou credenciais em saídas públicas.
