# Processar áudio do inbox com segurança

Verifique duração e estabilidade do arquivo, transcreva com Whisper base no mínimo, preserve o original, produza notas conectadas e só mova para processed após releitura.

## Segurança

Não copie memória, sessões, IDs, credenciais, dados pessoais, conteúdo restrito nem estado de execução para repositórios públicos.
