# Criar lembretes com estado no vault

Use um estado persistente e atômico, timezone America/Sao_Paulo e confirmação explícita antes de marcar algo como concluído.

## Segurança

Não copie memória, sessões, IDs, credenciais, dados pessoais, conteúdo restrito nem estado de execução para repositórios públicos.
