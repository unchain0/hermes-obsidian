# Ingerir um Markdown com readback

Leia o Markdown inteiro e sublinks pertinentes, escreva o máximo de notas úteis, releia e valide antes de arquivar o item.

## Segurança

Não copie memória, sessões, IDs, credenciais, dados pessoais, conteúdo restrito nem estado de execução para repositórios públicos.
