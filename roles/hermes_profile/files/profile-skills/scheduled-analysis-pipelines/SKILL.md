# Operar análises recorrentes

Separe coleta determinística de síntese por agente, mantenha estado fora do Git, torne execuções idempotentes e envie mensagens apenas quando houver resultado útil.

## Segurança

Não copie memória, sessões, IDs, credenciais, dados pessoais, conteúdo restrito nem estado de execução para repositórios públicos.
