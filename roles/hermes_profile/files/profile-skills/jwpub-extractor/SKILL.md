# Extrair pacotes JWPUB autorizados

Trate .jwpub como ZIP contendo SQLite. Extraia somente material obtido legitimamente, preserve proveniência e nunca publique conteúdo protegido.

## Segurança

Não copie memória, sessões, IDs, credenciais, dados pessoais, conteúdo restrito nem estado de execução para repositórios públicos.
