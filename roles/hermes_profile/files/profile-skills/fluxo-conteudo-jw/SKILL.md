# Fluxo público para conteúdo JW

Use somente jw.org e wol.jw.org como fontes religiosas. Leia links relevantes, preserve a origem permitida, sintetize em palavras próprias e não misture doutrinas externas. Não distribua publicações ou conteúdo restrito.

## Segurança

Nunca inclua tokens, IDs de chat, dados pessoais, conteúdo do vault real, estados de execução ou credenciais em saídas públicas.
