# Preparação semanal sanitizada

Colete a semana solicitada em fontes oficiais, produza material em PT-BR e grave no vault. Reexecuções aperfeiçoam a semana atual. Não publique dados congregacionais, designações ou manuais restritos.

## Segurança

Nunca inclua tokens, IDs de chat, dados pessoais, conteúdo do vault real, estados de execução ou credenciais em saídas públicas.
